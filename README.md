Profile Management System (Accura)

Project Overview

Accura is a web-based Profile Management System that helps users create and manage optimized profiles for platforms like LinkedIn, Indeed, Instagram, and Facebook. It analyzes user input and provides suggestions, templates, and insights to improve visibility and selection chances.

Objectives

- Let users choose a target platform (LinkedIn, Instagram)
- Collect relevant information for the selected platform
- Generate optimized profiles using predefined templates
- Provide feedback and proficiency score
- Estimate visibility and engagement probability

Features

- Multi-platform profile creation
- Profile analysis and feedback
- Predefined professional templates
- Preview and download in PDF format
- Secure login and data protection
- User-friendly interface

Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: ASP.NET Core (C#)
- Database: SQL Server
- IDE: Visual Studio 2022
- OS: Windows 10 or above
